# Рацион

Автоматический планировщик питания: генерация рационов под целевые КБЖУ с учётом предпочтений, ограничений и бюджета. Веб/PWA, российский рынок, mobile-first, интерфейс на русском.

## Запуск (разработка)

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Приложение поднимется на SQLite (`prisma/dev.db`), миграции применяются автоматически. Откройте http://localhost:3000 — вас встретит экран входа; зарегистрируйтесь по почте и паролю.

### Проверка с телефона (тот же Wi-Fi)

Dev-сервер слушает `0.0.0.0`. Узнайте IP компьютера (`ipconfig` в Windows → «IPv4-адрес») и откройте на телефоне `http://<IP>:3000`. При необходимости разрешите Node.js в брандмауэре Windows. Приложение можно установить на домашний экран как PWA.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Применяет миграции и запускает dev-сервер |
| `npm run build` | Продакшн-сборка (Next.js standalone) |
| `npm test` | Юнит-тесты ядра (Vitest) |
| `npm run typecheck` | Проверка типов TypeScript |
| `npm run seed` | Наполнение базы (появится в следующих срезах) |

## Стек

Next.js (App Router) + TypeScript + Tailwind, Prisma + SQLite (совместимо с PostgreSQL: смена `provider` и `DATABASE_URL`). Аутентификация — почта + пароль (bcrypt), серверные сессии в httpOnly-cookie. Дизайн-система — нативный iOS-стиль (Apple HIG).

Полный контекст и решения — в `.scratch/racion-mvp/` (карта, спецификация, тикеты) и `CONTEXT.md` (глоссарий). Деплой на VPS (docker-compose + PostgreSQL) — отдельным тикетом.
