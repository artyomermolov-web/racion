# 02 — Прототип: набор иконок-действий в стиле HIG

Type: prototype
Status: resolved (свёрнут в spec.md через to-spec; прототип не строился)

## Question

Действия приёма должны стать **иконками без текстовых подписей** (с `aria-label` — они уже есть в коде). HIG-иконки = SF Symbols, в вебе недоступны → делаем **свой набор инлайн-SVG** в стиле HIG (как `TabBar.tsx`), без зависимостей.

Собрать прототип (HTML/SVG, навык `prototype`), фиксирующий:
1. Глифы для: **«съел»** (галочка в круге / чек-состояние on/off), **«заменить»** (стрелки-круг / shuffle), **«удалить»** (корзина / ✕), **«добавить»** (плюс). Опционально: «перегенерировать», «избранное».
2. Единый визуальный язык: сетка 24×24, обводка/заливка, размеры/тап-таргеты (мин. 44pt по HIG), состояния (обычная/активная/disabled/busy).
3. Как иконка «съел» показывает три состояния: не съедено / съедено / в процессе (`busy`), не ломая доступность (`aria-pressed`).

Резолв: HTML-прототип со сравнением глифов, залинкованный от тикета; выбранный набор зафиксирован в ответе. Питает прототип ленты (04) и визуальное меню (03).
