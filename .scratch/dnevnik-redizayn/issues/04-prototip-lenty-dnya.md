## Question

Собрать прототип **главного экрана Дневника** — единой ленты дня по модели из тикета 01, с иконками из тикета 02. Зафиксировать:

1. **Раскладку ленты**: сводка остатка КБЖУ (кольца Б/Ж/У) сверху, приёмы по слотам, состояния приёма (предложено/съедено/…) визуально различимы.
2. **Раскрытие рецепта по тапу** — инлайн-аккордеон: тап по строке разворачивает состав + шаги + время, повторный тап сворачивает. Для «сырого продукта» (не рецепт) — компактная сводка КБЖУ/порции вместо шагов.
3. **Иконки-действия** на строке приёма: съел / заменить / удалить (набор из 02). Где живёт «Перегенерировать» (текстовая кнопка) и «+ Добавить».
4. Как в ленту встроен блок «Что поесть сейчас» (существующий `SuggestionsBlock`).
5. Вход в отдельный экран «Неделя» из шапки (тикет 06).

Резолв: HTML-прототип ленты, залинкованный от тикета; ключевые решения раскладки/взаимодействия — в ответе. Питает навигацию (05), неделю (06) и синтез спеки (07).
