Blocked by: 02, 03

## Question

Килфича и главный риск карты. Разрешается **прототипом** (HITL): дешёвый живой артефакт на реальном остатке/базе, на который пользователь реагирует, → фиксируем алгоритм скоринга и раскладку экрана. Вызвать Skill "prototype".

**Часть A — алгоритм `suggest.ts` (закрытие дельты).** Сигнатура из дизайна:
```
suggestNextMeal(input: {
  remaining: FoodNutrients, slot: Slot, candidates: GeneratorRecipe[],
  filters: { maxTimeMin?, mustNotCook?, equipment? },
  constraints: GeneratorConstraints, preferences?: Preferences, seed: number,
}): SuggestedMeal[]   // топ-3, детерминированно
```
Решить и зафиксировать:
- **Скоринг = закрытие взвешенного разрыва.** Для каждого кандидата подбираем порцию (переиспользуем `bestPortion`, но цель — **отстающий макрос**, а не только ккал) и считаем, насколько уменьшается взвешенный разрыв. Вес отстающего макроса выше → «добрать белок» реально закрывается. Штраф за перебор ккал. **Точные веса/формулу подобрать на прототипе на реальных числах.**
- **Всегда есть ответ.** Нет идеального → лучшие приближения с честной пометкой («добирает белок, но чуть выше по ккал»). Пусто — только при пустой базе (тогда явное сообщение).
- Жёсткие ограничения (аллергены/блок/keyword) и мягкие предпочтения (избранное/recurring) — через существующий `core/generator`, **ядро не меняем**.
- Фильтр усилий: **быстро / готовить / не готовить** (по `timeMin` и требуемой технике).
- **«Пересобрать остаток дня»** — вторичное действие: существующий генератор на оставшиеся слоты под `remaining` (точка входа «под остаток»).

**Часть B — прототип экрана дня** (расширяет систему «Трекер / Apple HIG», стиль не пере-решаем):
- Шапка с датой + день назад/вперёд.
- Сводка: кольцо «осталось ккал» + бары Б/Ж/У + клетчатка; **отстающий макрос подсвечен**.
- Главный блок «Что поесть сейчас» сразу под сводкой: 2–3 карточки (КБЖУ + время), чипсы **быстро/готовить/не готовить**, на карточке «съел» (лог в один тап) + «показать рецепт», вторичная «пересобрать остаток дня».
- Секции приёмов (завтрак/обед/ужин/перекус): записи (название · количество · ккал) + подытог; тап — правка, свайп — удалить; пустой приём → «+ добавить».

**Тесты (закладываем в спеку):** ранжирование закрывает отстающий макрос (при дефиците белка топ-вариант добирает белок); уважает ограничения/фильтр времени; детерминизм по seed; ≥1 вариант при непустой базе.

Прототип приложить как ассет (ссылка из тикета), не вставлять код в тело.
