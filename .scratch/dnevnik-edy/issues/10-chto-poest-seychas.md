# 10: «Что поесть сейчас» — подсказки + лог в один тап

**What to build:** Килфича. Под сводкой пользователь видит блок «Что поесть сейчас»: 2–3 конкретные карточки-варианта, каждая закрывает остаток КБЖУ с приоритетом на отстающий макрос (чаще белок), с КБЖУ и временем готовки. Чипсы **быстро / готовить / не готовить** фильтруют по времени и требуемой технике. Тап «съел» логирует вариант в один тап (запись `DiaryEntry` с пометкой происхождения) и двигает остаток; «показать рецепт» открывает рецепт; вторичная «пересобрать остаток дня» пересобирает несъеденные приёмы под остаток. Повторный тап не дублирует; удаление залогированной подсказки возвращает её в блок.

**Blocked by:** 08, 09

**Status:** ready-for-agent

Опирается на решения: спека [spec.md](../spec.md) (алгоритм зафиксирован; точные веса скоринга подбираются здесь против тестов). Ядро `/core/generator` не меняем — переиспользуем.

- [ ] `/core/diary/suggest.ts`: `suggestNextMeal(input) → SuggestedMeal[]` (топ-3, детерминированно). Подбор порции по `PORTION_STEPS` под отстающий макрос; скор = уменьшение взвешенного разрыва (вес отстающего макроса выше) + штраф за перебор ккал; фильтр усилий по `timeMin`/технике; честные пометки при неидеальном варианте; пусто только при пустой базе.
- [ ] `logDecision` (чистая идемпотентность по `date|slot|suggestedRecipeId`).
- [ ] Юнит-тесты `core/diary/suggest.test.ts` (при дефиците белка топ-вариант добирает белок; уважение аллергенов/блоков/keyword и фильтра времени/техники; детерминизм по seed; ≥1 вариант при непустой базе) + тест идемпотентности (повтор не дублирует; удаление возвращает подсказку).
- [ ] `src/lib/diary.ts`: `getSuggestions(date, filters)` — остаток + `dayTargetFromNorm`, кандидаты через существующие `RecipePool`/`poolForGeneration` + загрузчики предпочтений/ограничений, зов `suggestNextMeal`; лог подсказки с БД-guard `@@unique([userId, date, slot, suggestedRecipeId])`.
- [ ] Server action `logSuggestion` (идемпотентный).
- [ ] UI: блок «Что поесть сейчас» под сводкой — 2–3 карточки (КБЖУ+время), чипсы **быстро/готовить/не готовить**, «съел» (лог в один тап) + «показать рецепт», вторичная «пересобрать остаток дня» (переиспользует `regenerateDayRemainderForUser`), сообщение при пустой базе.

**Границы (сознательно НЕ здесь):** точная визуальная полировка/пустые тексты — тикет 12; прототип экрана не обязателен (система «Трекер / Apple HIG» уже задана).
