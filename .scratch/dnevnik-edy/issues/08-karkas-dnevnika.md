# 08: Каркас дневника — вкладка, день, сводка остатка

**What to build:** Пользователь открывает новую вкладку «Дневник» и сразу видит остаток КБЖУ за сегодня против своей нормы: кольцо «осталось ккал» + бары Б/Ж/У + клетчатка, с подсветкой отстающего макроса. Можно листать дни назад/вперёд. Пока записей нет — секции приёмов (завтрак/обед/ужин/перекус) пустые; без активного профиля — приглашение «заполни профиль». Это ходячий скелет: schema → lib → экран по вертикали прогресса, без ручного лога (он в тикете 09).

**Blocked by:** None (can start immediately)

**Status:** resolved
