## Answer

Полная заметка: [research/shtuki-i-istochniki.md](../research/shtuki-i-istochniki.md).

**1. Грамм-эквиваленты штук.** В сиде (`prisma/seed-data.ts`) штучные только яйца: С1=55 г, С0=65 г, перепелиное=12 г; всё прочее «штучное» заведено на вес (`unit="g"`, `gramsPerPiece=null`). Собрана референсная таблица «медианной штуки» для ~30 бытовых позиций (банан ~100 г мякоти, яблоко ~150, мандарин ~60 нетто, ломтик хлеба ~25, сосиска ~50, котлета ~90, огурец ~100, помидор ~120, зубчик чеснока ~5 и т.д.). ⚠ Разброс ±30–50 % (сорт/калибр/сезон); для фруктов различать брутто/нетто; ручной ввод граммов остаётся страховкой.

**2. Источники сегментов (факт по коду).**
- **Недавнее** → источника сегодня НЕТ; лога съеденного в схеме нет (останавливается на «срезе 12»), опора только на будущую `DiaryEntry` (тикет 02). ⚠ подтверждено — иного источника «истории» не существует.
- **Избранное** → есть `FavoriteRecipe { userId, recipeId }`, но это только **рецепты**; избранного/частого для **продуктов** нет ни модели, ни счётчика частоты (ближайшее — ручной `RecurringRecipe often/always`). «Частые продукты» = агрегат по будущей `DiaryEntry`. ⚠ развилка для тикета 06.
- **Своё** → `isCustom`+`ownerUserId` на `Ingredient` И `Recipe` (у Recipe ещё `baseRecipeId`). В поиск попадает через `where OR [ownerUserId null, ownerUserId userId]` (`food.ts`), помечается `own`; чистый список — `listCustomProducts` (`customFood.ts`). Готово как есть.
