# 09: Ручной лог — добавить / править / удалить запись

**What to build:** Пользователь добавляет съеденное в дневник вручную: жмёт «+ добавить» в приёме, ищет еду (сегмент **Поиск**), задаёт количество (граммы + чипсы-пресеты / штуки при наличии грамм-эквивалента / сервинги для рецепта) с живым превью КБЖУ, добавляет — запись появляется в секции приёма, подытоги и остаток пересчитываются. Запись можно тапнуть и поправить количество, свайпом удалить. Правка продукта в базе не меняет прошлые записи (снапшот).

**Blocked by:** 08
