## Question

Зафиксировать семантику остатка дня — вход для килфичи (тикет 04) и сводки экрана.

**1. Агрегация (`aggregate.ts`).** `summarize(entries) → totals`: суммы КБЖУ по приёмам и за день (ккал/Б/Ж/У/клетчатка). Подытоги на приём для секций экрана.

**2. Остаток/дельта (`progress.ts`).** `remaining(target, totals) → DayProgress`:
- `DayTarget` = **середины активного `NutritionProfile`** (в MVP ровно один активный; нет профиля → пустое состояние «заполни профиль», считать нечего).
- ккал + Б/Ж/У — со знаком: `remaining = target − eaten`; **перебор показывается честно** («+120 ккал сверх цели»), не обрезается в ноль.
- **клетчатка — только «добрать»** (min-only, без перебора), согласно `kbju-master.md`.
- Определить, что именно в `DayProgress`: остаток по каждому нутриенту, флаг/идентификатор **отстающего макроса** (чаще белок) для подсветки в сводке.

**3. Поздний старт / пропуски.** Остаток считается от факта на текущий момент (не «размазывает вину» по пропущенным приёмам); допускается закрыть остаток за 1–2 приёма (это уже поведение тикета 04, здесь только фиксируем, что `remaining` не привязан к «сколько приёмов осталось»).

**4. Тесты (Vitest, чистое ядро).** `aggregate` — суммы по приёму/дню; `progress` — дельта (минус/перебор/клетчатка min-only), выбор отстающего макроса при дефиците.
