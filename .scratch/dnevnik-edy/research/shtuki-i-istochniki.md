# Данные: грамм-эквиваленты «штук» + источники сегментов «Недавнее / Избранное / Своё»

> Заметка по тикету [01](../issues/01-dannye-shtuki-istochniki.md). Две справки: (1) референсные `gramsPerPiece` для штучных позиций; (2) факт-карта «сегмент потока добавления → реальная модель/поле/запрос» по коду репозитория. Собственная компиляция; проприетарные тексты не копировались.

## Часть 1. Грамм-эквиваленты штучных продуктов

### Что уже есть в сиде (факт)

`prisma/seed-data.ts` — единственные `unit="pcs"` продукты сегодня в группе «Яйца», у всех проставлен `gramsPerPiece`:

| Продукт (seed) | unit | gramsPerPiece (в коде) |
|---|---|---|
| Яйцо куриное С1 | pcs | **55** |
| Яйцо куриное С0 (отборное) | pcs | **65** |
| Яйцо перепелиное | pcs | **12** |
| Меланж / белок пастер. | ml | — (жидкость, поля нет) |

Всё остальное штучное «в быту» (банан, яблоко, ломтик хлеба, огурец…) в сиде заведено как `unit="g"` (продаётся на вес), поэтому `gramsPerPiece` у него `null`. Таблица ниже — референс на случай, когда такой продукт заводят как штучный (кастом-еда или расширение сида), а также для UI-конвертации «1 шт → г».

### Референсная таблица (масса съедобной части, 1 шт)

Значения — «медианная штука» típичного российского ритейла; разброс большой, поэтому колонка «Разброс/оговорка». КБЖУ в проекте задаётся на 100 г, поэтому `gramsPerPiece` — только множитель «шт → г»; на нутриенты на 100 г он не влияет.

| Позиция | Ср. масса, г | Разброс / оговорка |
|---|---|---|
| Яйцо куриное С1 | 55 | Категория С1 ~ 55–64.9 г с скорлупой; съедобная часть ~48–50 г. В сиде взято 55 (масса нетто ≈ калибр). |
| Яйцо куриное С0 (отборное) | 65 | С0 ~ 65–74.9 г со скорлупой. Верхняя категория; для СВ (высшая, >75 г) брать ~75. |
| Яйцо С2 | 48 | С2 ~ 45–54.9 г; если появится отдельной позицией. |
| Яйцо перепелиное | 12 | 10–14 г; мелкий калибр. |
| Банан (без кожуры) | 100 | Плод 150–200 г брутто, съедобно ~60–65 % → 90–120 г. Часто в рецептах считают «1 банан ≈ 100 г мякоти». |
| Яблоко (среднее) | 150 | Мелкое ~120, крупное ~200; огрызок ~10 %. «Среднее» столовое ~130–170 г. |
| Мандарин (без кожуры) | 60 | Плод ~70–90 г брутто, кожура ~20–25 % → мякоть 55–70 г. |
| Апельсин (без кожуры) | 130 | Плод ~180–220 г брутто, кожура ~25–30 % → 120–160 г мякоти. |
| Ломтик хлеба (батон/нарезка) | 25 | Тонкий ~20, толстый ~35; фабричная нарезка батона ~20–25 г, «Дарницкий» ломоть ~30–40 г. |
| Ломтик тостового хлеба | 30 | Формовой хлеб, 25–35 г ломтик. |
| Сосиска молочная | 50 | 40–60 г; зависит от фасовки (обычно 8–10 шт в упаковке ~450 г). |
| Сарделька | 100 | 90–120 г; крупнее сосиски. |
| Котлета (готовая, домашняя) | 90 | 70–120 г; полуфабрикат-котлета из сида ~ упаковка/шт варьирует. Для «столовой» котлеты берут ~80–100 г. |
| Огурец (средний) | 100 | Грунтовой 80–120, длинноплодный тепличный до 200–300 г. |
| Помидор (средний) | 120 | Черри ~15–20; сливка ~60–80; крупный бычье сердце 250–400 г. «Средний» ~100–130 г. |
| Зубчик чеснока | 5 | 3–7 г; головка ~30–50 г из ~8–12 зубчиков. |
| Луковица (средняя) | 100 | 70–150 г; мелкая ~50, крупная ~200. |
| Картофелина (средняя) | 100 | 70–150 г. |
| Морковь (средняя) | 90 | 70–120 г. |
| Перец болгарский (средний) | 150 | 120–200 г брутто; съедобно ~85 % (минус плодоножка/семена). |
| Киви | 75 | 60–100 г; съедобно почти всё, если с ложки. |
| Груша (средняя) | 170 | 130–220 г. |
| Хлебец ржаной | 10 | 8–12 г за пластину. |
| Булочка сдобная | 80 | В сиде packSize «1 шт (~80 г)»; сдоба 60–100 г. |
| Долька шоколада (стандартная плитка) | 5 | Плитка 100 г ≈ 20–24 дольки → ~4–5 г. |
| Печенье (шт) | 12 | Сильно зависит от вида: «Юбилейное» ~12–13 г, овсяное ~15–20 г. |
| Блин (средний) | 50 | 40–70 г; тонкий заварной ~40, толстый ~70. |
| Пельмень / вареник (шт) | 12 | Пельмень ~10–14 г, вареник ~20–25 г. |
| Кусок сахара-рафинада | 5 | Стандарт ~5.5 г (быстрорастворимый) или ~7.5 г (прессованный). |

⚠ **Оговорки:**
- Все значения — «медианная штука», реальный разброс легко ±30–50 % (сорт, калибр, сезон, регион). Для точности пользователь всегда может ввести граммы вручную (поток добавления, тикет 06).
- Для фруктов/овощей важно, брутто это или нетто (с кожурой/огрызком или без). В таблице для цитрусовых/банана указана **съедобная** масса (то, что реально идёт в КБЖУ); для яблока/помидора/огурца — практически весь плод.
- Яичные `gramsPerPiece` в сиде (55/65) фактически соответствуют массе нетто ≈ калибру категории, а не «съедобной части минус скорлупа». Это осознанное упрощение сида — при желании уточнить до ~48/58 г съедобного, но тогда КБЖУ на 100 г тоже относится к съедобной части, так что текущая пара «per100 сырого яйца + масса ≈ калибр» самосогласована для оценки.

## Часть 2. Источники сегментов потока добавления (факт по коду)

Проверено по `prisma/schema.prisma` (заголовок «срез 12»), `src/lib/food.ts`, `src/lib/customFood.ts`. Карта «сегмент → модель/поле/запрос»:

| Сегмент | Существует ли источник сегодня | Модель / поля | Как достаётся |
|---|---|---|---|
| **Недавнее** | ❌ Нет источника сегодня | Будущая таблица `DiaryEntry` (тикет 02) | Модели `DiaryEntry` в схеме **нет** (схема останавливается на «срезе 12»: `User/UserProfile/NutritionProfile/Ingredient/Recipe/...preferences/pantry/writeoff`). Никакого лога съеденного/истории добавления в БД сейчас нет → «Недавнее» может опираться **только** на будущие `DiaryEntry`. ⚠ Подтверждено: иного источника «что добавлял раньше» в коде не существует. |
| **Избранное** | ⚠ Частично: только рецепты | `FavoriteRecipe { userId, recipeId }` | Есть `model FavoriteRecipe` — но это **рецепт**, а не продукт: поля ровно `userId` + `recipeId`, `@@unique([userId, recipeId])`. Модели `Favorite`/`FavoriteIngredient` для **продуктов-ингредиентов нет**. «Избранных продуктов» как сущности не существует. |
| «Частые продукты» | ❌ Нет счётчика частоты | — | Частотности употребления/добавления в БД нет (нет `DiaryEntry`, нет счётчиков на `Ingredient`). Ближайшее по смыслу — `RecurringRecipe { userId, recipeId, frequency: "often"\|"always" }` (ручная пометка «регулярное», не автоподсчёт) и recurring-статус кастом-продуктов (`listCustomProducts` джойнит `RecurringRecipe` по строковому id ингредиента). ⚠ Настоящие «частые продукты» = агрегат по `DiaryEntry` (тикет 02); сегодня их вычислить не из чего. |
| **Своё** | ✅ Есть | `Ingredient.isCustom`+`Ingredient.ownerUserId`; `Recipe.isCustom`+`Recipe.ownerUserId` | Кастом-еда выражена парой `isCustom: Boolean @default(false)` + `ownerUserId: String?` на **обеих** моделях `Ingredient` и `Recipe` (у `Recipe` ещё `baseRecipeId` — персонализация базового). У обеих есть `@@index([ownerUserId])`. |

### Как «Своё» попадает в поиск/базу (факт)

- `getIngredients(userId)` (`src/lib/food.ts:59`) и `getRecipes(userId)` (`:80`): `where: { OR: [{ ownerUserId: null }, { ownerUserId: userId }] }` — база = общие (базовые) + свои; каждая строка помечается `own: r.ownerUserId === userId` (флаг для метки «Своё» в UI). Тот же `OR`-запрос в `listSelectableIngredients` (редактор состава рецепта).
- `listCustomProducts(userId)` (`src/lib/customFood.ts:40`): `where: { isCustom: true, ownerUserId: userId }` — чистый список «только моё», отсортирован `createdAt: "desc"`.
- `createCustomProduct` (`:67`): создаёт `Ingredient` с `isCustom: true, ownerUserId: userId, group: "Своё"` и заглушками упаковки/цены (`packSize:1, pricePerPack:0, shelfLifeDays:365`).
- Кастом-рецепт (`createCustomRecipe`, `:160`): `Recipe` с `isCustom: true, ownerUserId, baseRecipeId?` — своя версия вытесняет базовый в новых планах (см. `core/generator/custom.ts`).

### Итоговая карта для потока добавления (тикет 06)

- **Недавнее** → `DiaryEntry` (тикет 02), запрос вида «последние N записей пользователя, distinct по продукту/рецепту, order by `createdAt` desc». ⚠ до тикета 02 сегмент пустой.
- **Избранное** → `FavoriteRecipe` даёт только избранные **рецепты**. Избранных **продуктов** нет; если сегмент должен включать продукты — это отдельное решение (либо новая модель `FavoriteIngredient`, либо трактовать «частые» из `DiaryEntry`). Пометить в спеке как развилку.
- **Своё** → `Ingredient`/`Recipe` где `ownerUserId = userId` (плюс `isCustom`). Готово к использованию как есть, помечается `own`.

⚠ **Главные развилки для спеки:** (1) «Недавнее» и «частые продукты» полностью зависят от `DiaryEntry` — до тикета 02 источника нет; (2) «Избранное» сегодня = только рецепты, для продуктов сущности избранного не существует — нужно решение в тикете 06.
