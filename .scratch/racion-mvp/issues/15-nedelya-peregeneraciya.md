# 15: Неделя целиком + все уровни перегенерации

**What to build:** Пользователь получает полную неделю меню, средние КБЖУ за неделю попадают в диапазоны (отдельные дни могут отклоняться), блюда не повторяются слишком часто. Работает перегенерация на всех 4 уровнях (неделя / день / приём / блюдо), генерация недели быстрая.

**Blocked by:** 14

**Status:** resolved

Опирается на решения: 06. Расширяет генератор до недели (жадный проход + simulated annealing).

- [x] `/core/generator/week.ts` собирает неделю: жадный проход + simulated annealing (детерминированное число итераций); средние за неделю тянутся в диапазоны (высокий вес), дни могут отклоняться (низкий вес); перф-тест генерации недели ≤2 сек на базе ~300.
- [x] Анти-повторы «≤ maxPerWindow за окно» с адаптивным смягчением (мягкий штраф, не отсев) при нехватке кандидатов; исключения (остатки/always-recurring) — интерфейсный шов с пустым дефолтом, проводка отложена в 16/19. Окно «тонкого» слоя = сгенерированная неделя (см. док-коммент `RepeatPolicy`).
- [x] Перегенерация 4 уровней с автодополнением: неделя (заново), день (фокусный отжиг под остаток недели), приём/блюдо (`replaceMealInWeek` под остаток дня — в однодишевом слое приём и блюдо совпадают).
- [x] Тесты «на утечки»: зелёные 1,2,3,4,5,6,9,10,11,12 (аллерген, блок, keyword, слот/техника/время, недельные средние, адаптивные повторы, порции, автодополнение регена, перф, детерминизм). Тесты 7 (бюджет) и 8 (кладовка) отложены в тикеты 18/19 — нужны данные стоимости/лотов (оговорено в тикете 06).
- [x] Экран недели (`WeekPlan.tsx`): недельное среднее против диапазонов с ✓/⚠, честный баннер-компромисс, переключатель дней, приёмы дня, реген неделя/день/приём.
