## Question

Как запускается и живёт приложение? Зафиксировать: локальный dev на SQLite одной командой; docker-compose с PostgreSQL как задел; путь деплоя на VPS позже; настройку PWA (манифест, иконки, сервис-воркер: кэшировать статику и последние планы, API не кэшировать); как пользователь откроет с телефона на этапе проверки. Результат — короткий план окружений и команд запуска (для README).

## Answer

**Подтверждено пользователем.**

- **Разработка (по умолчанию):** SQLite. Запуск одной командой — `npm install` затем `npm run dev`. Скрипт сида (`npm run seed`, либо авто при первом запуске) наполняет продукты/рецепты. Prisma migrate для схемы.
- **Проверка с телефона:** dev-сервер слушает `0.0.0.0`, открываем с телефона в том же Wi-Fi по `http://<IP-компьютера>:3000` (в README — как узнать IP; учесть брандмауэр Windows). Альтернатива — временный туннель.
- **PWA:** `manifest.json` + иконки; service worker кэширует **оболочку приложения и последние планы** (static + last plans), запросы к **API — network-only** (не кэшируем). Установка на домашний экран.
- **Продакшн (задел, позже):** `Dockerfile` (Next.js standalone) + `docker-compose.yml` с **PostgreSQL**. Переключение SQLite→Postgres — сменой `provider` и `DATABASE_URL` (+ `prisma migrate deploy`). За HTTPS-прокси (Caddy c авто-TLS или nginx+certbot) на VPS.
- **README (рус.):** «запуск одной командой» + раздел «деплой на VPS (docker-compose с Postgres)».

Реализация этих артефактов — в тикетах стройки (каркас/PWA — тикет 11, README — тикет 20).
