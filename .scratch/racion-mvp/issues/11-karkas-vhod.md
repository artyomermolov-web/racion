# 11: Каркас + вход в аккаунт

**What to build:** Пользователь открывает приложение, регистрируется по почте и паролю, входит и выходит, видит пустой домашний экран в iOS-стиле; приложение можно поставить на телефон как PWA (каркас). Тонкая сквозная дорожка через БД, авторизацию и дизайн-систему.

**Blocked by:** Нет (можно начинать сразу).

**Status:** resolved

Опирается на решения: 04 (модель), 08 (авторизация), 09 (iOS-стиль), 10 (окружение).

- [x] Проект поднимается одной командой `npm run dev` на SQLite; Prisma-схема с сущностями User/Session мигрируется.
- [x] Работают регистрация, вход, выход; пароль хранится хешем (bcrypt); сессия в httpOnly-cookie.
- [x] При регистрации есть галочка согласия и ссылка на страницу-заглушку политики конфиденциальности.
- [x] Базовые iOS-компоненты (крупный заголовок, segmented control, inset grouped list, таб-бар, светлая+тёмная тема) существуют как переиспользуемые.
- [x] Домашний экран доступен только после входа и показывает осмысленное пустое состояние.
- [x] Есть `manifest.json` и иконки; приложение предлагается к установке как PWA.
