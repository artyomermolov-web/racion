## Question

Какие расчётные основы и справочные диапазоны заложить? Нужно подтвердить: формула Миффлина–Сан Жеора, множители активности (1.2/1.375/1.55/1.725), корректировки цели (похудение −20%, набор +15%), повышение белка по сухой массе при известном % жира (1.6–2.2 г/кг); рекомендованные диапазоны макросов для диет-пресетов (похудение, набор массы, кето, вегетарианство, веган, средиземноморская, православный пост) и наборы исключений по группам продуктов для каждого пресета; правила православного поста (что исключается); канонические группы аллергенов и их синонимы для keyword-фильтров (молочка/глютен/яйца/рыба/мясо/птица/орехи/соя). Результат — справочная сводка, пригодная как основа для модуля расчётов и пресетов.

## Answer

Полная сводка — в `.scratch/racion-mvp/research/nutrition-norms.md` (7 разделов). Гист:

- **Миффлин–Сан Жеор**: `10·вес + 6.25·рост − 5·возраст + s` (муж +5, жен −161), по общей массе тела.
- **Активность**: 1.2 / 1.375 / 1.55 / 1.725 (+ опц. 1.9).
- **Цель**: −20% похудение / +15% набор — в пределах стандартных диапазонов; защитные минимумы ккал ~1200/1500.
- **Белок**: при известном % жира — 1.6–2.2 г/кг сухой массы (`LBM = вес·(1−%жир)`).
- **Пресеты**: таблицы Б/Ж/У + исключения групп для похудения, набора, кето, вегетарианства, вегана, средиземноморской, поста.
- **Аллергены**: 8 канонических групп (+ морепродукты) с русскими синонимами/словоформами для keyword-фильтра.

⚠ **Учесть в тикете 05**: православный пост завести таблицей «день → допустимые группы», не хардкодить один режим; кето-порог углеводов 20 vs 50 г; вегетарианство — дефолт lacto-ovo; арахис в группе «орехи»; овёс/глютен зависит от строгости. Числа — рабочие дефолты, не мед. предписания.
