## Question

Как выглядит и ощущается приложение? Сделать кликабельный/статичный прототип 2–3 ключевых экранов (карточка блюда + неделя меню + список покупок) в едином «аппетитном», mobile-first стиле, чтобы пользователь выбрал внешний вид до стройки. Определить: палитру, типографику, стиль карточек и заглушек блюд, тон интерфейса. Собственный дизайн, без копирования. Опирается на UX-паттерны из тикета 02. Прототип приложить как ассет к тикету.

## Answer

**Выбор пользователя:** стиль **B «Трекер»**, за основу дизайн-системы — **Apple Human Interface Guidelines**. Из трёх показанных направлений (A «Кухонная тетрадь», B «Трекер», C «Тёмный премиум») победил B — цифры/КБЖУ на первом плане, функциональность.

**Зафиксированное визуальное направление (нативный iOS-look):**
- **Принципы HIG:** clarity / deference / depth — контент вперёд, минимум хрома, читаемость.
- **Типографика:** системный шрифт (SF Pro на Apple-устройствах через `-apple-system`), фолбэк Inter/Golos Text для кириллицы на прочих платформах; крупные заголовки (Large Title 32px), body 16–17px, tabular-nums для чисел.
- **Палитра:** iOS system colors. Light: `--bg #f2f2f7`, карточки `#fff`, `--tint #007aff` (systemBlue). Dark: `--bg #000`, карточки `#1c1c1e`, tint `#0a84ff`. Полная поддержка светлой и тёмной тем (system + ручной тумблер).
- **Кольца КБЖУ:** концентрические кольца Б/Ж/У в духе «Активности» (Б `#ff375f`, Ж `#ff9f0a`, У `#30d158`) — семантические цвета, отдельные от tint.
- **Компоненты:** inset grouped lists (радиус 12), segmented control, nav large title с trailing-кнопкой, нижний таб-бар с материалом (blur), тап-таргеты ≥44pt, chevrons, «фото» блюд — градиентные заглушки со скруглением.
- **Три экрана:** Сегодня (кольца + приёмы), Рецепт (герой + статы + ингредиенты + шаги), Покупки (итог ₽ + сгруппированный список с чек-кружками).

**Прототип (ассет, throwaway):** `.scratch/racion-mvp/prototype/screens.html` → опубликован: https://claude.ai/code/artifact/56fa01db-28c9-47e5-8f6c-d8f3582ca9db . Код прототипа — не продакшн (без тестов/обработки ошибок); при стройке переписываем начисто, сохраняя это визуальное направление.

⚠ Примечание на будущее: HIG в 2025+ вводит «Liquid Glass»/расширенные материалы — при стройке свериться с актуальным HIG; сейчас взят проверенный набор паттернов iOS.
