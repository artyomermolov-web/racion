# 05 — Расчёт нормы КБЖУ и диет-пресеты

Type: grilling
Status: resolved
Blocked by: 03
HITL/AFK: HITL

## Question

Как именно считать норму и предлагать макросы в онбординге и профилях питания? Зафиксировать: пошаговую логику (Миффлин → активность → цель → белок по сухой массе), как показывать пользователю диапазоны min–max и давать редактировать до грамма, как объяснять расчёт «простыми словами», как применять и снимать диет-пресеты (исключения групп + рекомендованные диапазоны). Опирается на находки тикета 03.

## Answer

**Продуктовые решения (подтверждено):** цель показываем диапазоном + «подстроить вручную» до грамма; диет-пресетов в MVP нет (закрываем целью + ручной правкой + фильтрами/аллергенами; веган/вегетарианец = исключение групп); % жира спрашиваем опционально.

**Пошаговый расчёт (модуль `/core/nutrition`, чистый, тестируемый):**
1. **BMR** — Миффлин–Сан Жеор: `10·вес(кг) + 6.25·рост(см) − 5·возраст + s` (муж s=+5, жен s=−161).
2. **TDEE** = BMR × активность: sedentary 1.2 / light 1.375 / moderate 1.55 / high 1.725.
3. **Цель по ккал** = TDEE × {похудеть 0.8 / держать 1.0 / набрать 1.15}.
4. **Диапазон ккал** = цель ±5% (даёт генератору свободу для разнообразия; пользователь может сузить).
5. **Белок**:
   - если указан % жира → `LBM = вес·(1−%жир/100)`, диапазон `LBM × 1.6…2.2` г;
   - если не указан → `вес × 1.6…2.0` г/кг.
6. **Жир** — нижний порог `вес × 0.8` г/кг, диапазон до ~30% калорийности.
7. **Углеводы** — остаток калорий после белка и жира (в виде диапазона).
8. **Клетчатка (мин.)** — ~14 г на 1000 ккал (округляем до 25–30 г).
9. Натрий/холестерин — мягкие максимумы, низкий приоритет.

**Защита:** цель не опускается ниже ~1200 ккал (жен) / ~1500 (муж) — при попытке показываем мягкое предупреждение, не блокируем.

**Объяснение «простыми словами» в онбординге:** «Ваше тело тратит примерно **X ккал** в день. Чтобы худеть, берём на 20% меньше → **Y ккал**. Из них белок **A–B г**, жиры **C–D г**, углеводы **E–F г**.» С возможностью открыть «подстроить вручную».

**Пресеты (задел, не MVP):** отдельная модель не нужна — пресет = именованный набор {исключения групп продуктов + рекомендованные диапазоны макросов}, применяется поверх профиля и снимается. Реализация — отдельной волной; в MVP роль пресетов играют `KeywordFilter` + аллерген-исключения + ручные макросы.

**Правило:** изменение профиля/цели **никогда** не перегенерирует план само — только по кнопке (см. тикет 06).

Опирается на `research/nutrition-norms.md` (⚠ пост, кето-порог, подтипы вегетарианства — при добавлении пресетов).
