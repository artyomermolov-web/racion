# 14: Генерация дня

**What to build:** Приложение собирает один день меню под норму пользователя из базы; пользователь видит приёмы с блюдами, КБЖУ и кольцами Б/Ж/У, может перегенерировать день и заменить отдельное блюдо (новое подбирается под остаток дневных целей). Аллергены и несовместимые со слотом блюда никогда не попадают.

**Blocked by:** 12, 13

**Status:** resolved

Опирается на решения: 06 (генератор). Первый, «тонкий» слой ядра `/core/generator` (жёсткие ограничения + жадный проход + порции, уровень дня).

- [x] Модуль `/core/generator` собирает день под цель: жёсткие ограничения (аллергены, техника, время, совместимость слота) отсекают кандидатов; подбор порций 0.25–2.0 под цель приёма.
- [x] Юнит-тесты «на утечки»: аллерген не просачивается; несовместимый слот не проходит; порции в диапазоне; детерминизм при фиксированном seed.
- [x] Экран дня показывает приёмы, КБЖУ и кольца Б/Ж/У против цели.
- [x] Кнопки «перегенерировать день» и «заменить блюдо» работают; замена автодополняет под остаток дня.
- [x] Изменение настроек не перегенерирует план само.

**Границы «тонкого» слоя (в этом тикете сознательно НЕ сделано):** мягкие штрафы/бонусы, бюджет, кладовка, избранное/блоки/keyword-фильтры, анти-повторы за 14 дней, недельный simulated annealing, жёсткие ограничения по калоражу/белку/соли/жирам из kbju-master.md C (в «тонком» слое калораж — мягко, через скоринг) и персистентность плана (Plan/PlanItem) — тикеты 15–19. Ядро уже принимает `excludedAllergens` и покрыто тестами «на утечки»; проводка персональных аллергенов в UI — тикет 16 (пока список пуст).

**Про «настройки не перегенерируют план» (criterion 5).** В сессии план живёт в состоянии клиента и меняется только по кнопкам — сам собой не пересобирается. Начальная сборка детерминирована по seed от (userId + дата), поэтому перезагрузка в тот же день даёт тот же план — но при изменившейся норме цель дня другая, и план на следующей загрузке отразит новую норму. Полная стабильность плана между перезагрузками (даже при правке нормы) требует персистентности — тикет 19.
