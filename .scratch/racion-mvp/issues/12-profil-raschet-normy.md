# 12: Профиль и расчёт нормы

**What to build:** Пользователь вводит физданные (пол, возраст, рост, вес, активность, цель, опционально % жира), видит рассчитанную персональную норму КБЖУ диапазоном с объяснением простыми словами, может подстроить её до грамма и сохранить; норма отображается на домашнем экране.

**Blocked by:** 11

**Status:** resolved

Опирается на решения: 03, 05 (расчёты). Реализует ядро `/core/nutrition`.

- [x] Модуль `/core/nutrition` считает норму (Миффлин → активность → цель → диапазон ±5%; белок по сухой массе при известном %жира); покрыт юнит-тестами (Vitest), включая граничные и защитные минимумы ккал.
- [x] Форма профиля сохраняет данные пользователя (UserProfile) и активную цель (NutritionProfile).
- [x] Норма показана диапазоном ккал и Б/Ж/У с текстовым объяснением расчёта.
- [x] Пользователь может вручную подстроить диапазоны до грамма и сохранить.
- [x] Норма видна на домашнем экране после сохранения.
