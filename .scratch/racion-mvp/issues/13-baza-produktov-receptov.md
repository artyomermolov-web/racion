# 13: База продуктов и рецептов

**What to build:** Пользователь листает и ищет продукты и рецепты, открывает карточку рецепта с пошаговым приготовлением и КБЖУ. В базе есть стартовый набор данных, достаточный для генерации; КБЖУ рецепта считается автоматически из ингредиентов.

**Blocked by:** 11

**Status:** ready-for-agent

Опирается на решения: 01 (данные), 04 (модель). Полное наполнение — в тикете 21.

- [ ] Схема Ingredient / Recipe / RecipeIngredient + теги (аллергены/слоты/диеты/техника) через join-таблицы.
- [ ] Скрипт сида наполняет стартовый набор (продукты + рецепты, достаточно для сборки недели); запускается `npm run seed`.
- [ ] КБЖУ рецепта вычисляется из состава, не хранится вручную.
- [ ] Экран базы: список с поиском и сортировкой по нутриенту; карточка рецепта с ингредиентами и шагами.
- [ ] Правдоподобность выборочно проверена (напр. суп ~300–500 ккал).
