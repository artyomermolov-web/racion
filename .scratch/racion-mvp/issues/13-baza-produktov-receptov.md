# 13: База продуктов и рецептов

**What to build:** Пользователь листает и ищет продукты и рецепты, открывает карточку рецепта с пошаговым приготовлением и КБЖУ. В базе есть стартовый набор данных, достаточный для генерации; КБЖУ рецепта считается автоматически из ингредиентов.

**Blocked by:** 11

**Status:** resolved

Опирается на решения: 01 (данные), 04 (модель). Полное наполнение — в тикете 21.

- [x] Схема Ingredient / Recipe / RecipeIngredient + теги (аллергены/слоты/диеты/техника) через join-таблицы.
- [x] Скрипт сида наполняет стартовый набор (продукты + рецепты, достаточно для сборки недели); запускается `npm run seed`.
- [x] КБЖУ рецепта вычисляется из состава, не хранится вручную.
- [x] Экран базы: список с поиском и сортировкой по нутриенту; карточка рецепта с ингредиентами и шагами.
- [x] Правдоподобность выборочно проверена (напр. суп ~300–500 ккал).
