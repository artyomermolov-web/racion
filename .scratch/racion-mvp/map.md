# Карта: Рацион MVP

`wayfinder:map`

## Destination

Рабочее приложение **«Рацион» (MVP)** — веб/PWA-планировщик питания под целевые КБЖУ для российского рынка, которое пользователь открывает с телефона и проходит путь: онбординг с расчётом нормы → сгенерированная неделя меню → правки блюд → список покупок целыми пачками с суммой в ₽ → кладовка (перенос купленного, приоритет генератора) → отметка «съел».

Эта карта сначала фиксирует ключевые решения (тикеты-вопросы ниже), а затем по ней же ведётся стройка. Расширения — следующими волнами (см. «Not yet specified»).

## Notes

**Спецификация:** [spec.md](./spec.md) — синтез закрытых решений этой карты (готова к стройке, `ready-for-agent`).

**Домен:** см. `CONTEXT.md` в корне репозитория (глоссарий терминов). При изменении модели домена вызывать навыки `grilling` + `domain-modeling`.

**Планировщик исполнения:** этот маршрут доводит до стройки. После закрытия решающих вопросов (тикеты 04–10) в туман добавляются тикеты-волны стройки MVP и graduate по мере снятия решений. То есть карта — это и решения, и последующий план работ.

**Стек (зафиксирован вводными):** Next.js (App Router) + TypeScript + Tailwind, mobile-first, PWA. Prisma + SQLite для разработки, схема совместима с PostgreSQL. Генератор меню — чистый модуль `/core/generator` без зависимостей от Next.js, покрыт тестами (Vitest). Аккаунты email + пароль (bcrypt, сессии).

**Стандартные преференции:** весь интерфейс на русском; валюта ₽; метрические единицы; неделя с понедельника; русский формат даты. Собственные тексты/дизайн/рецепты — ничего не копируем у Eat This Much и др.

**Планка качества:** сначала для себя / узкого круга, но архитектура с прицелом на рост «до уровня страны» (Postgres-совместимость, мультиюзер, чистое ядро генератора). Без пейволов; под подписки — только технический задел, без реализации.

**По типам тикетов вызывать навыки:** `research` → Skill "research"; `prototype` → Skill "prototype"; `grilling` → Skill "grilling" + "domain-modeling"; `task` → выполнить работу и записать факты.

## Decisions so far

<!-- по одной строке на закрытый тикет: гист ответа + ссылка -->

- [01 — Данные о продуктах РФ (КБЖУ, фасовки, цены)](issues/01-dannye-produkty-rf.md): готова сид-таблица на 211 продуктов в 13 группах (`research/products-ru.md`). ⚠ цены — лишь ориентир (регион/сезон/промо), для прода нужен живой источник; скрытые аллергены сверять по составу.
- [02 — Функциональность Eat This Much + находки piknifood](issues/02-razbor-etm-piknifood.md): перенять 3 уровня перегенерации + autocomplete, систему предпочтений и правило «настройки не перегенерируют молча» (ETM); модель пачек/цен/остатков и разделение реальные/pending/snapshot (piknifood); доставка в РФ — только список+экспорт в MVP, интеграция позже. Детали — в `research/competitors.md`. Разблокирует 09.
- [03 — Нормы КБЖУ, диет-пресеты, аллергены, пост](issues/03-normy-kbju-presety.md): Миффлин–Сан Жеор + активность 1.2–1.725, цель −20%/+15%, белок 1.6–2.2 г/кг LBM; таблицы макросов и исключений по 7 пресетам; 8 групп аллергенов с синонимами. Детали и ⚠-оговорки — в `research/nutrition-norms.md`. Разблокирует 05.
- [04 — Модель данных MVP](issues/04-model-dannyh-mvp.md): зафиксирован набор Prisma-сущностей (User/Profile/NutritionProfile/MealType/DaySetting/Ingredient/Recipe/Plan/PlanItem/вкусы/GroceryList/PantryLot + задел). Одна активная цель, единая раскладка на все дни, приёмы Завтрак/Обед/Ужин/Перекус. Теги — join-таблицы (портируемость SQLite↔PG). Разблокирует 06, 07.
- [05 — Расчёт нормы КБЖУ и диет-пресеты](issues/05-raschet-normy-presety.md): Миффлин→активность→цель(0.8/1.0/1.15)→диапазон ±5%; белок по LBM при известном %жира, иначе по весу; жир/углеводы/клетчатка диапазонами; цель показываем диапазоном + ручная правка; пресетов в MVP нет (заменяют фильтры+аллергены); защитные минимумы ккал. Разблокирует 06 (теперь свободен).
- [06 — Алгоритм генератора меню](issues/06-algoritm-generatora.md): чистый модуль `/core/generator`; жёсткие ограничения → пул кандидатов, скоринг `E=штрафы−бонусы` (приоритет КБЖУ>разнообразие>экономия), подбор порций, жадный проход + simulated annealing (неделя ≤2с), недельные средние в диапазонах, перегенерация 4 уровней с автодополнением, адаптивные анти-повторы, бюджет опционален, «настройки не перегенерируют сами». Определены 12 тестов «на утечки».
- [07 — Список покупок пачками + кладовка](issues/07-spisok-pokupok-kladovka.md): потребность×люди×порции − real-кладовка → ceil до пачек → чек ₽; три состояния запасов real/pending/snapshot строго раздельно; живой синк + заморозка ручных правок; подтверждение = снапшот цен + перенос в real-лоты; списание по факту «съел» с guard'ом от двойного вычитания. 7 тестов. Период — неделя от дня закупки.
- [09 — Визуальный стиль](issues/09-vizualnyy-prototip.md): выбран стиль **«Трекер» на базе Apple HIG** — нативный iOS-look (SF Pro/системный шрифт, system colors light+dark, кольца Б/Ж/У как в «Активности», inset grouped lists, segmented control, таб-бар с материалом). Прототип: `prototype/screens.html` (throwaway) → https://claude.ai/code/artifact/56fa01db-28c9-47e5-8f6c-d8f3582ca9db
- [08 — Аутентификация и приватность](issues/08-auth-akkaunty-privatnost.md): email+пароль (bcrypt) + серверные сессии; регистрация без подтверждения, но со сбросом пароля; соц-вход Яндекс/VK и подписки — задел; приватность по-минимуму (согласие + заглушка политики), полный 152-ФЗ при росте.
- [10 — Стратегия деплоя](issues/10-strategiya-deploya.md): dev — SQLite, `npm run dev` + сид; проверка с телефона по локальной сети; PWA (кэш оболочки+планов, API network-only); прод — docker-compose+Postgres на VPS за HTTPS. README рус.
