## 1. Формула Миффлина–Сан Жеора (BMR / RMR)

Оценивает базовый обмен веществ (Basal Metabolic Rate, ккал/сутки в покое). Считается наиболее точной
из простых формул по массе тела для широкой популяции (точнее, чем Харрис–Бенедикт).

**Общая форма:**

```
BMR = 10 × вес(кг) + 6.25 × рост(см) − 5 × возраст(лет) + s
```

- **Мужчины:** `s = +5`
- **Женщины:** `s = −161`

Развёрнуто:

```
Муж:  BMR = 10·вес + 6.25·рост − 5·возраст + 5
Жен:  BMR = 10·вес + 6.25·рост − 5·возраст − 161
```

### Примеры расчёта

**Пример 1 — мужчина**, 30 лет, 80 кг, 180 см:
```
BMR = 10·80 + 6.25·180 − 5·30 + 5
    = 800 + 1125 − 150 + 5
    = 1780 ккал/сутки
```

**Пример 2 — женщина**, 30 лет, 65 кг, 165 см:
```
BMR = 10·65 + 6.25·165 − 5·30 − 161
    = 650 + 1031.25 − 150 − 161
    = 1370.25 ≈ 1370 ккал/сутки
```

**Пример 3 — мужчина**, 45 лет, 95 кг, 178 см:
```
BMR = 10·95 + 6.25·178 − 5·45 + 5
    = 950 + 1112.5 − 225 + 5
    = 1842.5 ≈ 1843 ккал/сутки
```

**Замечания:**
- Формула использует **общую массу тела** (не сухую). Для очень тучных людей может завышать BMR ⚠.
- Единицы: вес — кг, рост — см, возраст — полные годы.
- BMR затем умножается на множитель активности → получаем TDEE (суточный расход, см. §2).

## 2. Множители активности (PAL → TDEE)

`TDEE = BMR × множитель активности`

TDEE (Total Daily Energy Expenditure) — суммарный суточный расход энергии.

| Множитель | Уровень | Словами (что означает) |
|-----------|---------|------------------------|
| **1.2**   | Сидячий (sedentary) | Минимум движения: офисная/удалённая работа, почти нет спорта, преимущественно сидячий образ жизни. |
| **1.375** | Лёгкая активность (lightly active) | Лёгкие тренировки/спорт **1–3 раза в неделю**, либо работа с небольшими нагрузками. |
| **1.55**  | Умеренная активность (moderately active) | Умеренные тренировки/спорт **3–5 раз в неделю**. |
| **1.725** | Высокая активность (very active) | Интенсивные тренировки **6–7 раз в неделю**, активный образ жизни. |
| *(1.9)*   | *Экстремальная (extra active)* | *Очень тяжёлый физический труд + тренировки дважды в день, профессиональный спорт. Не входит в базовый набор, но часто добавляется как 5-й уровень.* ⚠ |

**Замечания:**
- Это классическая шкала Харриса–Бенедикта, применяемая и к BMR по Миффлину.
- ⚠ Множители — приблизительная эвристика. Реальный NEAT (нетренировочная активность) сильно варьирует,
  поэтому TDEE полезно уточнять по факту через 2–4 недели наблюдения за весом.

## 3. Корректировки под цель (калорийный сдвиг)

От TDEE применяется поправка под цель:

| Цель | Дефолт в ТЗ | Насколько стандартно / диапазоны |
|------|-------------|----------------------------------|
| **Похудение** | −20% | Общепринятый умеренный дефицит **10–25%** (часто −15…−20%). −20% — разумный дефолт. Более агрессивно (−25…−30%) — только краткосрочно и при высоком % жира. ⚠ |
| **Поддержание** | 0% (= TDEE) | Стандарт: без изменений. |
| **Набор массы** | +15% | Профицит обычно **+5…+20%**. Для «чистого» набора чаще рекомендуют **+10…+15%** (≈ +200–400 ккал), чтобы минимизировать набор жира. +15% — верхняя граница «чистого» набора, приемлемо. ⚠ |

**Ориентиры по темпу (для валидации):**
- Безопасное похудение: **0.5–1% массы тела в неделю** (≈ 0.5–1 кг для 70–100 кг). Дефицит ~500 ккал/сут ≈ −0.5 кг/нед.
- Набор для новичков/натуралов: **~0.25–0.5% массы в неделю** (быстрее → больше жира).

**Защитные ограничения (рекомендуется в продукте):** ⚠
- Не опускать целевую калорийность **ниже BMR** и не ниже ~**1200 ккал/сут (жен)** / **1500 ккал/сут (муж)**
  без медицинского контроля.
- Дефицит/профицит считать от TDEE, а не от BMR.

## 4. Повышение белка по сухой массе тела (LBM)

Когда известен процент жира, точнее нормировать белок на **сухую массу тела (LBM, lean body mass)**, а не на общую массу.

**Расчёт LBM:**
```
LBM = вес × (1 − %жира/100)
```
Пример: 90 кг, 25% жира → LBM = 90 × 0.75 = **67.5 кг**.

**Норма белка:**
- Общий ориентир для активных людей / на дефиците: **1.6–2.2 г на кг** (по LBM, если он известен; иначе — по общей массе).
- ISSN: **1.4–2.0 г/кг** для тренирующихся; при дефиците и сохранении мышц — **до 2.2–3.1 г/кг LBM** ⚠ (верх — агрессивная «сушка»).

**Когда применять по LBM:**
- Известен % жира (замер, биоимпеданс, оценка). Тогда `белок = k × LBM`, где k ≈ 1.6–2.2.
- Особенно важно при **избыточном весе/ожирении**: нормировка на общую массу завысила бы белок.
- При похудении (сохранение мышц) и при наборе массы — верхняя часть диапазона.

**Практическое правило для пресетов:**
| Ситуация | Белок |
|----------|-------|
| Поддержание, % жира неизвестен | 1.6 г/кг общей массы |
| Похудение, % жира известен | 1.8–2.2 г/кг LBM |
| Набор массы | 1.6–2.0 г/кг общей массы (или LBM) |

⚠ Верхняя граница (>2.2 г/кг) не даёт доказанного преимущества для большинства и осмысленна лишь при жёсткой сушке.
При заболеваниях почек высокий белок противопоказан — нужна оговорка в продукте.

## 5. Рекомендованные диапазоны макросов по пресетам

Обозначения: **Б** — белки, **Ж** — жиры, **У** — углеводы. Проценты — от суточной калорийности.
Калорийность: 1 г Б = 4 ккал, 1 г У = 4 ккал, 1 г Ж = 9 ккал.

| Пресет | Белки (Б) | Жиры (Ж) | Углеводы (У) | Примечания |
|--------|-----------|----------|--------------|------------|
| **Похудение** | 30–35% (или 1.8–2.2 г/кг LBM) | 25–30% | 35–40% | Высокий белок для сытости и сохранения мышц; дефицит калорий. |
| **Набор массы** | 25–30% (1.6–2.0 г/кг) | 20–30% | 40–50% | Больше углеводов для тренировок и профицита. |
| **Кето** | 20–25% | **70–75%** | **5–10% (≤ 20–50 г/сут)** | Резкое ограничение углеводов; жир — основной источник энергии. ⚠ |
| **Вегетарианство** (lacto-ovo) | 15–20% | 25–30% | 50–55% | Молочка и яйца остаются; белок из бобовых, молочки, яиц. |
| **Веган** | 15–20% | 25–30% | 50–60% | Только растительное; следить за B12, железом, омега-3, белком. |
| **Средиземноморская** | 15–20% | **30–40%** (оливковое масло, рыба, орехи) | 40–50% | Акцент на ненасыщенных жирах, рыбе, овощах, цельных злаках. Не столько про %, сколько про качество/структуру. |
| **Православный пост** | варьирует | варьирует | высокие У | Не диета для КБЖУ, а свод пищевых ограничений (см. §6). Макросы смещаются к растительным У и Ж; белок падает (кроме постных дней с рыбой). ⚠ |

**Базовые «безопасные» границы (WHO / общие):**
- Белок: не ниже ~0.8 г/кг (RDA-минимум), обычно 1.2–2.2 г/кг для активных.
- Жиры: не ниже 20% калорийности (гормоны, усвоение витаминов A/D/E/K), обычно 20–35%.
- Углеводы: 45–65% для «обычных» рационов; кето — исключение.

⚠ Проценты — ориентиры. В генераторе разумнее задавать **белок в г/кг** (фиксируем), **жир — нижний порог** (напр. ≥ 0.8 г/кг),
а углеводы — «остаток» калорийности.

## 6. Исключения по группам продуктов для пресетов

Что убираем (для keyword-фильтров и правил генерации):

### Похудение / Набор массы
Явных исключений групп продуктов нет — регулируются калорийностью и макросами. Опционально: ограничение
«пустых калорий» (сахар, фастфуд) — но это не жёсткое исключение группы.

### Кето
- **Резко ограничены углеводы**: ≤ 20–50 г/сут.
- **Убираем/минимизируем:** сахар и сладости, хлеб/выпечку, крупы и злаки (рис, гречка, овсянка, макароны),
  картофель и крахмалистые овощи, большинство фруктов (кроме ягод в малых количествах), бобовые, мёд, соки, сладкие напитки.
- **Оставляем:** мясо, рыбу, яйца, сыр, масла/жиры, орехи, некрахмалистые овощи.

### Вегетарианство (lacto-ovo — самый распространённый вариант)
- **Убираем:** мясо, птицу, рыбу и морепродукты (всё, что требует убоя животного).
- **Оставляем:** молочку, яйца, мёд, растительные продукты.
- ⚠ Разновидности: *lacto* (без яиц), *ovo* (без молочки), *pescetarian* (+ рыба — формально не вегетарианство).
  Для дефолта берём lacto-ovo.

### Веган
- **Убираем всё животное:** мясо, птицу, рыбу/морепродукты, молочку (молоко, сыр, творог, йогурт, сливочное масло),
  яйца, мёд, желатин, а также животные добавки (сыворотка, казеин).
- **Оставляем:** только растительное (бобовые, злаки, овощи, фрукты, орехи, семена, растительные масла/молоко).

### Средиземноморская
- **Не исключает группы жёстко**, а задаёт приоритеты/ограничения:
  - Приоритет: овощи, фрукты, цельные злаки, бобовые, рыба, оливковое масло, орехи.
  - **Ограничиваем:** красное мясо, обработанное мясо (колбасы), рафинированный сахар, сильно обработанную пищу, сливочное масло (замена — оливковое).

### Православный пост ⚠ (высокая вариативность правил)
Не единый режим, а **степени строгости по дням**. Базово в постные периоды **исключаются:**
- **Мясо и птица** (всегда в пост).
- **Молочные продукты** (молоко, сыр, творог, сливочное масло и т.п.).
- **Яйца.**

Что **допускается** — зависит от строгости конкретного дня:
| Степень строгости | Что разрешено |
|-------------------|---------------|
| Строгий пост / сухоядение | Растительная пища без термической обработки и без масла; вода. |
| Без масла | Варёная растительная пища, но **без растительного масла**. |
| С растительным маслом | Растительная пища + растительное масло (и часто вино). |
| **С рыбой** (рыбные дни) | Дополнительно разрешена **рыба** (напр. Благовещение, Вербное воскресенье; в определённые дни постов). |

**Замечания ⚠:**
- Календарь и правила определяются церковным уставом (Типикон) и меняются по дням недели и праздникам —
  для продукта разумно вынести это в отдельную таблицу «день → допустимые группы», а не хардкодить один режим.
- Морепродукты (кальмары, креветки) в народной практике часто трактуют как «постные» даже в дни без рыбы — **спорно** ⚠.
- Растительное масло и рыба — ключевые «переключатели» строгости.

## Краткое резюме

- **§1 Миффлин–Сан Жеор** подтверждена: `10·вес + 6.25·рост − 5·возраст + s` (муж +5, жен −161). Приведены 3 примера. Использует общую массу тела.
- **§2 Множители** активности 1.2 / 1.375 / 1.55 / 1.725 расшифрованы словами; отмечен опциональный 5-й уровень 1.9.
- **§3 Корректировки цели:** −20% (похудение) и +15% (набор) — в пределах стандартных диапазонов (дефицит 10–25%, профицит 5–20%). Даны защитные пороги.
- **§4 Белок по LBM:** формула `LBM = вес·(1−%жир)`, k = 1.6–2.2 г/кг LBM; применять при известном % жира, особенно у людей с избыточным весом.
- **§5 Макросы по пресетам:** сведены в таблицу с % и г/кг; рекомендация — фиксировать белок в г/кг, жир по нижнему порогу, углеводы как остаток.
- **§6 Исключения групп** расписаны по каждому пресету, включая веган (всё животное) и кето (углеводы).
- **§7 Словари аллергенов** (8 групп + морепродукты отдельно) с русскими синонимами и словоформами для keyword-фильтра.

### Спорные / неоднозначные места (⚠)
1. **Православный пост** — самый вариативный блок: правила зависят от церковного устава, конкретного дня и праздника (сухоядение / без масла / с маслом / с рыбой). Рекомендуется таблица «день → допустимые группы», а не единый режим. Статус морепродуктов спорен.
2. **Множители активности** — грубая эвристика; TDEE лучше калибровать по факту динамики веса за 2–4 недели.
3. **Верхняя граница белка** (>2.2 г/кг) не даёт доказанной пользы большинству; противопоказана при болезнях почек.
4. **Кето-порог углеводов** (20 vs 50 г) варьирует между источниками.
5. **Вегетарианство** имеет подтипы (lacto / ovo / lacto-ovo / pesco) — взят дефолт lacto-ovo.
6. **Аллергены-исключения:** арахис относят к «орехам» (ботанически — бобовое); кокос — спорно; «белок» многозначно; овёс по глютену зависит от строгости целиакии.
7. Все числа — ориентиры, не медицинские предписания; в продукте нужны защитные минимумы калорийности (~1200/1500 ккал) и оговорки для мед. состояний.
