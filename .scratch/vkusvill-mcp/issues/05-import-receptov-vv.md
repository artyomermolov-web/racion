# 05: Импорт рецептов ВкусВилл

**What to build:** Рецепты из ВкусВилл попадают в базу Racion с шагами и структурными КБЖУ и становятся доступны генератору; импортируются только при достаточном сопоставлении ингредиентов.

**Blocked by:** 02

**Status:** done

Опора: [spec](../spec.md) (Q6=a).

- [x] Чистый `core/vkusvill/recipe.ts`: `recipeToRecipe(vvRecipe, catalogIndex) → {recipe, matchedRatio}`; импорт при `matchedRatio ≥ 0.8`, иначе пропуск + тест (≥80% импорт, <80% пропуск, перенос шагов/аллергенов).
- [x] Пометка происхождения рецепта (поле из тикета 01/схемы).
- [x] Подключение к `vv:sync`: импортируемые рецепты тянут нужные товары в охват.
- [x] Меню-единица остаётся `Recipe` Racion; КБЖУ из структурного `nutritional`/из состава.
- [x] Демо: импортированный рецепт ВВ виден в базе и попадает в сгенерированный план.

## Заметки о слайсе

- `recipeToRecipe` (шов 1, чистый) + `recipe.test.ts` (17 кейсов): импорт при ≥80%,
  пропуск при <80%, перенос шагов (массив/HTML-строка), union аллергенов по
  сопоставленным ингредиентам, слияние повторов, `categoryToSlots`.
- Схема: на `Recipe` добавлены `source`/`vvId` (@unique)/`vvUpdatedAt` +
  миграция `recipe_vkusvill_provenance`.
- Мэтч ингредиентов рецепта — по `id`/`xml_id` товара ВВ; `vv:sync` строит
  `catalogIndex` по обоим ключам (рецепт может ссылаться на любой) и делает
  идемпотентный upsert рецептов (ключ `vvId`). Фикстуры `SAMPLE_RECIPES`.
- Меню-единица — `Recipe` Racion, `ownerUserId=null`: КБЖУ считается из состава,
  аллергены выводятся из ингредиентов (как во всём приложении). Структурный
  `nutritional` ВВ хранится в выходе только для аудита.
- Демо (`npm run vv:sync -- --offline`): рецепт «Гречка с куриной грудкой и
  огурцом» импортирован (100%), «Творожная запеканка» пропущена (33%);
  импортированный рецепт попадает в сгенерированную неделю (12/20 прогонов).
- Известные границы (см. код-ревью): при импорте <100% аллергены/КБЖУ несопоставленной
  части не переносятся — порог ≥80% это ограничивает; хранение структурных КБЖУ/
  аллергенов рецепта — отдельный тикет (противоречит модели «КБЖУ из состава»).
