# 05: Импорт рецептов ВкусВилл

**What to build:** Рецепты из ВкусВилл попадают в базу Racion с шагами и структурными КБЖУ и становятся доступны генератору; импортируются только при достаточном сопоставлении ингредиентов.

**Blocked by:** 02

**Status:** ready-for-agent

Опора: [spec](../spec.md) (Q6=a).

- [ ] Чистый `core/vkusvill/recipe.ts`: `recipeToRecipe(vvRecipe, catalogIndex) → {recipe, matchedRatio}`; импорт при `matchedRatio ≥ 0.8`, иначе пропуск + тест (≥80% импорт, <80% пропуск, перенос шагов/аллергенов).
- [ ] Пометка происхождения рецепта (поле из тикета 01/схемы).
- [ ] Подключение к `vv:sync`: импортируемые рецепты тянут нужные товары в охват.
- [ ] Меню-единица остаётся `Recipe` Racion; КБЖУ из структурного `nutritional`/из состава.
- [ ] Демо: импортированный рецепт ВВ виден в базе и попадает в сгенерированный план.
