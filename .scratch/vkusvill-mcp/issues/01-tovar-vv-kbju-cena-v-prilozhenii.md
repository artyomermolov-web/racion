# 01: Настоящие КБЖУ и цена товара ВкусВилл в приложении

**What to build:** Тонкий сквозной путь: продукт в приложении показывает настоящие КБЖУ и цену из ВкусВилл с бейджем провенанса. Это трейсер-буллет — устанавливает весь хребет интеграции (сеть → схема → парсинг → маппинг → синк → UI) на узком наборе товаров.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

Опора: [spec](../spec.md), [ADR-0001](../../../docs/adr/0001-vkusvill-edinyy-istochnik-sync.md), `CONTEXT.md` (Товар ВВ, Провенанс).

- [x] Минимальный MCP-адаптер `src/lib/vkusvill/client.ts` (JSON-RPC, `tools/call`, конверт `{ok,data}`, UTF-8) — только методы, нужные этому слайсу; единственная точка сети.
- [x] Поля на `Ingredient`: `source` (`seed|vkusvill`, default `seed`), `vvXmlId?` (индекс), `vvPriceOld?`, `vvDiscountPct?`, `vvUpdatedAt?` + миграция Prisma.
- [x] Чистый парсер `core/vkusvill/parse.ts` (`parseVkusvillNutrition → FoodNutrients`, усреднение по поставщикам) + тест на фикстурах.
- [x] Чистый маппер `core/vkusvill/map.ts` (`productToIngredient`, штучный/весовой, скидка в отдельные поля, категория→group) + тест на фикстурах.
- [x] Синк небольшого набора товаров в Prisma (upsert по `vvXmlId`), проставляет `source="vkusvill"`.
- [x] Карточка продукта показывает реальные КБЖУ/цену ВВ и бейдж «данные ВкусВилл».
- [x] Демо: выбранный продукт «оживает» на данных ВВ; `npm run build` зелёный.

## Comments

**Выполнено** (коммит `fb7b0c1`). Спина реализована: чистые `core/vkusvill`
(parse/map, 17 тестов на фикстурах), адаптер `lib/vkusvill/client.ts`, поля
провенанса + миграция, `npm run vv:sync` (идемпотентный upsert по `vvXmlId`),
бейдж «Данные ВкусВилл» + реальная цена в База/Продукты. `npm run build`
зелёный, вся сюита 391 тест зелёная.

Известные ограничения слайса (в рамках трейсер-буллета): (1) публичный MCP
держит жёсткий per-IP rate-limit (429) — живой синк ждёт снятия лимита, для
демо/дев есть `npm run vv:sync -- --offline` на фикстурах реального формата;
(2) `vvXmlId` сделан `@unique` (сильнее «индекса» — нужно для идемпотентного
upsert); (3) КБЖУ-строки ВВ обычно без клетчатки/натрия → эти поля 0 у
ВВ-товаров; (4) карточка = строка списка База/Продукты (отдельной детали у
ингредиентов в приложении нет). Аллергены ВВ-товаров, ре-сорс seed и
частичная смета — тикеты 02/03.
