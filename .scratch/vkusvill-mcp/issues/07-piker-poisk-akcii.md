# 07: Пикер добавления через поиск ВкусВилл + бейдж «Акция»

**What to build:** Визуальный пикер добавления продукта ищет по каталогу ВкусВилл и добавляет реальные товары; акционные товары помечены бейджем и фильтруются.

**Blocked by:** 01

**Status:** ready-for-agent

Опора: [spec](../spec.md) (Покрытие функций MCP), существующий тикет 12 «визуальный пикер».

- [ ] Server action поиска: `products_search` (пагинация, категории-фасеты, сортировки).
- [ ] Пикер: поиск по каталогу ВВ, карточка с КБЖУ/ценой/картинкой; добавление создаёт/ссылается на `Ingredient` с `vvXmlId` (парсер/маппер из тикета 01).
- [ ] Акции: бейдж «Акция» (`vvDiscountPct`/`price.old`) + фильтр «только акционные» (`products_discount`).
- [ ] Бейджи по группе (эмодзи) сохраняются; `group` — русская подпись.
- [ ] Мягкая деградация: при недоступности ВВ — поиск по локальному снапшоту.
- [ ] Демо: поиск товара ВВ в пикере, добавление, видны акции.
