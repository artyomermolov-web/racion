**Status:** done

## Заметки о реализации

- Ядро: `ShoppingIngredient.source?: "seed"|"vkusvill"`; строка получает `priced` (цена реальна только у `vkusvill`), `lineCost = priced ? … : 0`. Список — `partial`/`excludedCount`. «Дыра» = покупаемая позиция (`packsToBuy>0`) без реальной цены; полностью покрытые кладовкой (0 пачек) дырой не считаются.
- Слой данных `lib/shopping.ts` пробрасывает `Ingredient.source` из БД.
- UI: бейдж «приблизительно» + `≈` у итога, у несопоставленных вместо ₽ показывается «цена ?». В снапшот покупки несопоставленные уезжают с ценой 0 (продукт в кладовку попадает, но сумму не выдумываем).
- Демо-состояние: сейчас в базе 6 сопоставленных с ВВ из 212 (охват тикета 02), покупаемые позиции текущей недели все несопоставлены → смета честно `≈ 0 ₽` с 4 пробелами. По мере расширения курируемого мэтчинга (тикет 02) в смете появится реальная сумма рядом с пробелами.
