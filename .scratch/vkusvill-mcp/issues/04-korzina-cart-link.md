# 04: Кнопка «Открыть корзину во ВкусВилл»

**What to build:** Со списка покупок пользователь одним действием получает ссылку(и) на предзаполненную корзину ВкусВилл; длинный список бьётся на несколько корзин ≤20 позиций.

**Blocked by:** 02

**Status:** done

Опора: [spec](../spec.md) (Q2/Q11), `CONTEXT.md` (Ссылка-корзина).

- [x] Чистый `core/vkusvill/cart.ts`: `buildCartChunks(lines) → {xml_id,q}[][]` — только позиции с `vvXmlId`, группы ≤20, `q` 0.01–40 + тест (одна/несколько групп, дробные `q`, пропуск без `vvXmlId`, зажим q). 11 тестов, TDD.
- [x] Server action `createCartLinksAction`: по каждой группе live `cart_link_create` → массив `share_basket`-URL; мягкая деградация при лимите/сбое ВВ.
- [x] UI: кнопка «Открыть корзину во ВкусВилл» на списке покупок; при нескольких группах — несколько ссылок с пояснением; кнопка видна только при наличии сопоставленной покупаемой позиции.
- [x] Это ссылка, не заказ/оплата, без авторизации — финансовых действий не выполняем (пометка в UI и в адаптере/экшене).
- [x] Демо: клик собирает группы и зовёт `cart_link_create` (проверено в браузере: 1 группа из сопоставленной позиции). Рабочую ссылку с живого ВВ в песочнице получить нельзя — MCP недоступен/rate-limit; путь успеха отдаёт `share_basket`-ссылки, путь сбоя — понятное сообщение (подтверждено).

**Заметки о слайсе.**
- `vvXmlId` проброшен через домен `shopping` (`ShoppingIngredient`/`ShoppingLine` → `list.ts` → `lib/shopping.ts`), чтобы клиент знал SKU для корзины.
- Форма live-вызова — допущения (нет фикстуры из-за rate-limit): ключ аргумента `products` и имя поля ссылки в ответе (`share_basket`/`url`). Подтвердить и сузить при первом успешном live-вызове. Сеть — вне юнит-тестов (spec.md Testing Decisions).
