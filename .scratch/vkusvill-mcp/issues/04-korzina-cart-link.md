# 04: Кнопка «Открыть корзину во ВкусВилл»

**What to build:** Со списка покупок пользователь одним действием получает ссылку(и) на предзаполненную корзину ВкусВилл; длинный список бьётся на несколько корзин ≤20 позиций.

**Blocked by:** 02

**Status:** ready-for-agent

Опора: [spec](../spec.md) (Q2/Q11), `CONTEXT.md` (Ссылка-корзина).

- [ ] Чистый `core/vkusvill/cart.ts`: `buildCartChunks(lines) → {xml_id,q}[][]` — только позиции с `vvXmlId`, группы ≤20, `q` 0.01–40 + тест (одна/несколько групп, дробные `q`, пропуск без `vvXmlId`).
- [ ] Server action: по каждой группе live `cart_link_create` → массив `share_basket`-URL.
- [ ] UI: кнопка на списке покупок; при нескольких группах — несколько ссылок с пояснением.
- [ ] Это ссылка, не заказ/оплата, без авторизации — финансовых действий не выполнять.
- [ ] Демо: клик → рабочая ссылка(и) на корзину ВВ.
