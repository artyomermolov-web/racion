# 06: «Заменить» через аналоги ВкусВилл (экран Неделя)

**What to build:** На экране Неделя кнопка «Заменить» предлагает аналоги из ВкусВилл, и выбор заменяет позицию.

**Blocked by:** 02

**Status:** ready-for-agent

Опора: [spec](../spec.md) (Покрытие функций MCP), существующий тикет 13 «неделя→замена».

- [ ] Server action: по `vvXmlId` позиции вернуть аналоги через `product_analogs` (полные карточки).
- [ ] UI на экране Неделя: список аналогов (название/КБЖУ/цена), выбор → замена позиции.
- [ ] Если у позиции нет `vvXmlId` — понятное сообщение (аналоги недоступны).
- [ ] Мягкая деградация при недоступности ВВ (кнопка не роняет экран).
- [ ] Демо: замена блюда на ВВ-аналог прямо на Неделе.
