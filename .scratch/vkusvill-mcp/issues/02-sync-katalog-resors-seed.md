**What to build:** Команда `npm run vv:sync` наполняет каталог настоящими данными ВкусВилл по курируемому охвату и ре-сорсит существующие seed-ингредиенты по мэтчингу; провенанс проставлен по всему каталогу.

**Blocked by:** 01

**Status:** resolved

Опора: [spec](../spec.md) (Синк, Q4/Q8/Q5), [ADR-0001](../../../docs/adr/0001-vkusvill-edinyy-istochnik-sync.md).

- [x] Чистый мэтчер `core/vkusvill/match.ts` (`matchIngredient`, нормализация названий, порог, `null` при неоднозначности) + тест.
- [x] Расширение адаптера/клиента: пагинация по `page` (лимит 10/стр., `meta.has_more`), бэкофф на 429 (`analogs` вместо `details` где можно).
- [x] `npm run vv:sync`: курируемый охват (нужные пищевые категории + товары под импортируемые рецепты + стартовый набор); идемпотентный upsert.
- [x] Ре-сорс: seed-ингредиенты при мэтче → настоящие КБЖУ/цена + `source="vkusvill"`+`vvXmlId`; иначе `source="seed"` (фолбэк).
- [x] ⚠️ Расширение каталога сдвинет детерминированные недельные leak-тесты генератора — починить на уровне генератора/вердикта, не подбором данных под seed (память проекта).
- [x] Демо: прогон команды → каталог на данных ВВ, провенанс виден; `npm run build` зелёный.

## Comments

**Выполнено.** Реализованы: чистый мэтчер `core/vkusvill/match.ts`
(`matchIngredient` + `normalizeName`, коэффициент Дайса по токенам, порог 0.6,
разрешение ничьей по группе, `null` при неоднозначности — 12 тестов на
фикстурах, TDD); пагинация клиента `productsSearchAll` (итерация по `page`,
`meta.has_more`, cap страниц, мягкая остановка на ошибке/лимите — бэкофф на 429
уже жил в `callTool`); переписан `vv:sync` — курируемый охват категорий +
идемпотентный upsert + ре-сорс seed-строк на месте (id сохраняется,
`source="vkusvill"`+`vvXmlId`). Провенанс проставлен по всему каталогу.

Демо (оффлайн-фикстуры, `npm run vv:sync -- --offline`): из 6 товаров ВВ 5
ре-сорснули seed-строки (`grechka`, `tvorog5`, `moloko32`, `ogurcy`,
`yaytso-c0`) настоящими КБЖУ/ценой/скидкой, 1 (филе цыплёнка) не дотянул до
порога и честно завёлся новой строкой — консервативность матчера (лучше
фолбэк, чем чужие цифры). Повторный прогон идемпотентен (0 новых/ре-сорса, 6
обновлений на месте, без дублей). В приложении (База → Продукты) на
ре-сорснутых строках виден бейдж «Данные ВкусВилл». `npm run build` зелёный,
вся сюита 403 теста зелёная.

Границы (осознанно вне этого тикета):
- **`analogs` вместо `details`**: синк ходит только `products_search` (mode=full
  уже отдаёт КБЖУ/цену), поэтому `details`/`analogs` ему не нужны; заводить
  неиспользуемые сетевые методы = мёртвый код. `analogs` придёт в тикете 06
  («Заменить»). Бэкофф на 429 — реализован (в `callTool`).
- **Товары под импортируемые рецепты + стартовый набор рецептов**: сам импорт
  рецептов — тикет 05; пока рецептов ВВ нет, охват ведётся по пищевым
  категориям. Расширение охвата рецепто-товарами — вместе с тикетом 05.
- **Leak-тесты (⚠️)**: не сдвинулись и правки не потребовали — недельные
  генераторные тесты читают `SEED_RECIPES` из `seed-recipes.fixture.ts`
  (компиляционный импорт `prisma/seed-data.ts`), а не Prisma-каталог, куда
  пишет синк. Пункт проверен и закрыт как no-op.
- **Частичная смета** (позиции без мэтча вне суммы + флаг `partial`) — тикет 03.
