# 02: Курируемый синк каталога + ре-сорс seed

**What to build:** Команда `npm run vv:sync` наполняет каталог настоящими данными ВкусВилл по курируемому охвату и ре-сорсит существующие seed-ингредиенты по мэтчингу; провенанс проставлен по всему каталогу.

**Blocked by:** 01

**Status:** ready-for-agent

Опора: [spec](../spec.md) (Синк, Q4/Q8/Q5), [ADR-0001](../../../docs/adr/0001-vkusvill-edinyy-istochnik-sync.md).

- [ ] Чистый мэтчер `core/vkusvill/match.ts` (`matchIngredient`, нормализация названий, порог, `null` при неоднозначности) + тест.
- [ ] Расширение адаптера/клиента: пагинация по `page` (лимит 10/стр., `meta.has_more`), бэкофф на 429 (`analogs` вместо `details` где можно).
- [ ] `npm run vv:sync`: курируемый охват (нужные пищевые категории + товары под импортируемые рецепты + стартовый набор); идемпотентный upsert.
- [ ] Ре-сорс: seed-ингредиенты при мэтче → настоящие КБЖУ/цена + `source="vkusvill"`+`vvXmlId`; иначе `source="seed"` (фолбэк).
- [ ] ⚠️ Расширение каталога сдвинет детерминированные недельные leak-тесты генератора — починить на уровне генератора/вердикта, не подбором данных под seed (память проекта).
- [ ] Демо: прогон команды → каталог на данных ВВ, провенанс виден; `npm run build` зелёный.
