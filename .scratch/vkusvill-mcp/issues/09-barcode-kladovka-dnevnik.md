# 09: Добавление продукта по штрихкоду

**What to build:** Пользователь добавляет продукт в кладовую или дневник по штрихкоду — товар находится в ВкусВилл и добавляется с настоящими КБЖУ.

**Blocked by:** 01

**Status:** ready-for-agent

Опора: [spec](../spec.md) (Покрытие функций MCP).

- [ ] Server action: `product_barcode` (EAN-13) → карточка товара ВВ.
- [ ] UI: ввод/скан штрихкода → найденный товар → добавить в кладовую (лот) или дневник.
- [ ] Создание/связывание `Ingredient` с `vvXmlId`, КБЖУ через парсер (тикет 01).
- [ ] Rate-limit семейства detail/barcode (429): бэкофф + понятное сообщение при неудаче.
- [ ] Не найдено → предложить ручной ввод/поиск.
- [ ] Демо: скан штрихкода → продукт добавлен с данными ВВ.
