# База расчёта питания — мастер-документ

Единый опорный документ проекта для расчёта КБЖУ и генерации меню.
Объединяет: коэффициенты расчёта энергии + принципы рациона (BIOMACHINE / доказательная нутрициология) + проверенные источники.
Все расчёты калорийности и все правила подбора блюд берут значения отсюда.

Части:
- **A. Расчёт энергии и КБЖУ** — математика (коэффициенты, формулы, нормы).
- **B. Принципы рациона** — правила подбора продуктов и структуры меню.
- **C. Ограничения для solver'а** — как A и B превращаются в жёсткие/мягкие ограничения.
- **D. Проверенные источники** — актуальная доказательная база с датами.

# ЧАСТЬ A. РАСЧЁТ ЭНЕРГИИ И КБЖУ

## A1. Правило по умолчанию

Энергия продукта на 100 г:
`ккал = белок × Кб + жир × Кж + (углеводы − клетчатка) × Ку + клетчатка × 2.0 + спирт × 7.0`

где Кб, Кж, Ку — коэффициенты группы продукта (A3). Если группа неизвестна — общие факторы (A2).
Клетчатка считается отдельно и НЕ входит в «углеводы» для энергии.
Округление только в финале: энергия — до целых ккал, макросы в меню — до целого грамма.

## A5. Термический эффект пищи (TEF) — слой для целей набора/сушки

НЕ применять к отображаемым калориям (ломает сверку с этикетками).
Только для внутреннего расчёта реального профицита/дефицита.

| Нутриент | TEF | Остаётся телу, ккал/г |
|---|---|---|
| Белок | 20–30% (расч. 0.25) | ~3.0 |
| Углеводы | 5–10% (расч. 0.08) | ~3.7 |
| Жир | 0–3% (расч. 0.02) | ~8.8 |
| Смешанный рацион | ~10% | — |

Чистый профицит при наборе:
`чистые_ккал = белок × 4.0 × 0.75 + углеводы × 4.0 × 0.92 + жир × 9.0 × 0.98`

## A7. Суточная норма калорий

**Шаг 1. BMR — Миффлин–Сан Жеор (1990):**
- мужчины: `10 × вес_кг + 6.25 × рост_см − 5 × возраст + 5`
- женщины: `10 × вес_кг + 6.25 × рост_см − 5 × возраст − 161`

**Шаг 2. TDEE = BMR × коэффициент активности:**

| Активность | Коэффициент |
|---|---|
| Сидячий | 1.2 |
| Лёгкая (1–3 трен/нед) | 1.375 |
| Средняя (3–5 трен/нед) | 1.55 |
| Высокая (6–7 трен/нед) | 1.725 |
| Очень высокая (2 трен/день) | 1.9 |

**Шаг 3. Цель:**
- набор: +10–15% к TDEE (1 кг ткани ≈ 7700 ккал; +0.3 кг/нед ≈ +330 ккал/день)
- поддержание: TDEE
- сушка: −15–20% от TDEE

## A8. Целевое распределение БЖУ

| Нутриент | Норма | Расчёт |
|---|---|---|
| Белок (набор/поддержание) | 1.6–2.2 г/кг | вес × 2.0 |
| Белок (сушка) | 2.0–2.6 г/кг | вес × 2.2 |
| Жир | 0.8–1.2 г/кг, не ниже 0.6 | вес × 1.0 |
| Углеводы | остаток калорий | (ккал − белок×4 − жир×9) / 4 |
| Клетчатка | 14 г/1000 ккал (≥25–30 г) | ккал/1000 × 14 |
| Вода | 30–40 мл/кг + 500 мл/час трен. | вес × 0.035 |

Порядок: фиксируем белок и жир от веса → углеводы забирают остаток калоража.

# ЧАСТЬ B. ПРИНЦИПЫ РАЦИОНА

Основа: доказательная нутрициология BIOMACHINE (Роман Овчаров), Тарелка Гарварда, ВОЗ 2023.
Реконструкция из открытых материалов; формулировки платного курса дословно не воспроизводятся.

## B1. Философия (пять установок)

1. **Еда в первую очередь, добавки — потом.** Добавки закрывают реальный дефицит, а не маркетинг.
2. **Важны суточные итоги, а не идеальность каждого приёма.** Балансируем день, а не тарелку.
3. **Цельные продукты вместо переработанных.** Минимум сахара, промышленной еды, трансжиров.
4. **Белок — фундамент**, из обычной еды (яйца, курица, творог, рыба), а не из порошка.
5. **Без искусственных запретов.** Устойчивость важнее строгости.

## B2. Тарелка Гарварда — пропорция дня (не каждого приёма)

| Компонент | Доля | Что входит |
|---|---|---|
| Овощи и фрукты | 50% | овощи > фруктов; картофель НЕ овощ |
| Цельные крупы | 25% | гречка, овёс, бурый рис, киноа, ц/з хлеб |
| Белок | 25% | рыба, птица, яйца, творог, бобовые |
| Масла | в меру | растительные; сливочное — ограниченно |

## B3. Конкретные нормы (defaults, подтверждены ВОЗ 2023)

| Параметр | Значение | Источник |
|---|---|---|
| Овощи + фрукты | ≥ 400 г/день | ВОЗ 2023 |
| Клетчатка | ≥ 25 г/день (14 г/1000 ккал) | ВОЗ 2023 |
| Белок | 1.6–2.2 г/кг | спортивная нутрициология |
| Насыщенные жиры | ≤ 10% калоража | ВОЗ 2023 |
| Трансжиры | ≤ 1% калоража | ВОЗ 2023 |
| Общий жир | ≤ 30% калоража | ВОЗ 2023 |
| Добавленный сахар | ≤ 10%, стремиться к 5% | ВОЗ |
| Соль | ≤ 5 г/день, йодированная | ВОЗ |
| Вода | 30–40 мл/кг + трен. | |
| Приёмы пищи | 3–5 по удобству | частота не влияет на результат |

## B4. Приоритет продуктов (веса для подбора)

**Повышенный вес:** рыба и морепродукты (2–3 р/нед), яйца, творог, птица, нежирное мясо, цельные крупы, бобовые, разноцветные овощи и зелень, ягоды, орехи/семена (по калориям), нерафинированные масла.

**Пониженный вес:** добавленный сахар, кондитерка, сладкие напитки, переработанное мясо, рафинированные крупы и мука, фастфуд, трансжиры, алкоголь.

**Нейтрально:** молочка, сыр (по жиру и соли), картофель (как крахмал, не как овощ).

## B5. Добавки — только по реальному дефициту

| Добавка | Когда оправдана |
|---|---|
| Витамин D | почти всем в РФ осень–зима, по анализу 25(OH)D |
| Омега-3 | если рыбы < 2–3 р/нед |
| Креатин моногидрат | силовые тренировки (доказанная польза) |
| Магний | при дефиците, лучше из еды |
| Йод | если соль не йодированная |

**Не рекомендованы:** коллаген, BCAA при достаточном белке, жиросжигатели, «детокс», экзотические соли.

# ЧАСТЬ C. ОГРАНИЧЕНИЯ ДЛЯ SOLVER'А

**Жёсткие (нарушать нельзя):**
- аллергены и персональный стоп-лист → 0
- калораж дня в коридоре −5%…+5% от цели
- белок дня ≥ целевого
- соль ≤ 5 г/день
- насыщенные жиры ≤ 10% калоража, трансжиры ≤ 1%

**Мягкие (штраф за отклонение):**
- калораж: штраф за модуль отклонения от цели
- овощи + фрукты < 400 г → штраф
- клетчатка < нормы → штраф
- добавленный сахар > 10% → штраф
- структура дня далеко от 50/25/25 → штраф
- рыба < 2 р/нед → штраф
- переработанное мясо / рафинат в меню → штраф
- повтор блюда в пределах недели → штраф

**Бонусы:** сезонные и местные продукты; использование уже купленных (нулевые остатки); продукты из «приоритета» (B4).

**Порядок минимизации:** аллергены/соль/жиры (жёсткие) → калораж → белок → клетчатка+овощи → структура тарелки → разнообразие → остальное.

# ЧАСТЬ D. ПРОВЕРЕННЫЕ ИСТОЧНИКИ

Актуальная доказательная база. Для каждого — за что он отвечает.

## D1. Данные о продуктах (КБЖУ, микронутриенты)

- **USDA FoodData Central** — https://fdc.nal.usda.gov/
  Мировой эталон состава продуктов. Основной источник значений на 100 г для наполнения каталога. Обновляется постоянно.
- **Роспотребнадзор, база «Химический состав продуктов»** (Скурихин, официальные таблицы РФ)
  Для российских продуктов, которых нет в USDA (местные сорта, локальная продукция).

## D2. Коэффициенты пересчёта энергии

- **FAO. Food energy — methods of analysis and conversion factors (2003)** — https://www.fao.org/uploads/media/FAO_2003_Food_Energy_02.pdf
  Первоисточник факторов Атуотера (общих и специфичных), клетчатки, спирта. Раздел A2–A6 взят отсюда.
- **FAO y5022e, Chapter 3** — https://www.fao.org/4/y5022e/y5022e04.htm
  Таблицы специфичных факторов по группам продуктов (раздел A3).

## D3. Нормы потребления (сколько чего в день)

- **ВОЗ. Обновлённые руководства по жирам и углеводам (17 июля 2023)** — https://www.who.int/news/item/17-07-2023-who-updates-guidelines-on-fats-and-carbohydrates
  Актуальные нормы: жиры ≤30%, насыщенные ≤10%, трансжиры ≤1%, клетчатка 25 г, овощи/фрукты ≥400 г. Раздел B3 взят отсюда.
- **ВОЗ. Guideline: Sugars intake (2015, действует)** — https://www.who.int/publications/i/item/9789241549028
  Добавленный сахар ≤10% калоража, цель <5%.
- **МР 2.3.1.0253-21 «Нормы физиологических потребностей в энергии и пищевых веществах для населения РФ» (Роспотребнадзор, 22.07.2021)** — https://base.garant.ru/402816140/
  Официальные российские нормы БЖУ, витаминов и минералов. Приоритетный источник для РФ.
- **EFSA. Dietary Reference Values** — https://www.efsa.europa.eu/en/topics/topic/dietary-reference-values
  Европейские референсные значения по нутриентам, для сверки.

## D4. Расчёт энергозатрат и белка

- **Mifflin MD, St Jeor ST (1990). A new predictive equation for resting energy expenditure.** Am J Clin Nutr.
  Формула BMR (раздел A7) — на сегодня самая точная для здоровых взрослых.
- **ISSN Position Stand: Protein and Exercise (2017, действует)** — https://jissn.biomedcentral.com/articles/10.1186/s12970-017-0177-8
  Нормы белка 1.4–2.0 г/кг для тренирующихся, до 2.2–3.1 при сушке. Раздел A8.
- **ACSM/спортивная нутрициология** — коэффициенты активности для TDEE.

## D5. Принципы рациона

- **Harvard T.H. Chan School of Public Health — Healthy Eating Plate** — https://nutritionsource.hsph.harvard.edu/healthy-eating-plate/
  Первоисточник модели 50/25/25 (раздел B2).
- **BIOMACHINE (Роман Овчаров)** — https://biomachine.global/ , https://t.me/bmchn
  Методология подачи и приоритеты доказательного подхода (часть B). Транслирует мейнстрим-науку выше.

## D6. Что НЕ является источником

Не использовать для расчётов: блоги без ссылок на исследования, данные производителей БАД, «нутрициологов» без первоисточников, устаревшие таблицы до 2003 (клетчатка = 0), маркетинговые материалы.
